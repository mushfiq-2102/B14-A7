# Project Name: বাজার দর (BazarDor)

## Description:
**BazarDor** is a Bengali price-tracking web app. It shows today's prices of rice, pulses, oil, vegetables, fish, meat, eggs and spices, how much each price changed since yesterday and a market-by-market price breakdown for every product.


#### Features
1. Live price ticker: an infinite scrolling strip under the navbar showing emoji, name, price per unit.
2. Daily price movers: top 6 risers and top 6 fallers on the home page.
3. All products grid: every product as a responsive card with Bengali digits and a green/red/gray change badge.
4. Category pages with sorting: sort by default, price low → high or high → low, with skeleton loading and an empty state.
5. Protected product details: min/max/ average price summary and a market-wise price table for each product.
6. Authentication: email/password plus Google & GitHub login with toast feedback for login, signup, logout and protected-route redirects.
7. Profile & update information: view your profile and update your name on a separate route.
8. Fully responsive: mobile, tablet and desktop with a custom 404 page for unknown routes.
